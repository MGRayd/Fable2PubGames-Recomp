FABLE II - PUB GAMES RECOMPILED

This package does not contain the original game.

1. Run Fable2PubGamesLauncher.exe.
2. Choose your own legally obtained Xbox 360 Pub Games container.
3. Select Install Game Files.
4. Select Play Pub Games.

The launcher extracts game content locally into the data folder.

Fable II linking is available under Advanced Options. Choose the saves folder
from Fable II Recompiled and enable syncing. Do not run both games at once.
Backups are created before Fable II bridge records are updated.
